## 現在の方針

候補群ごとに
「指示書作成 → 監査 → 正式発行 → 実行」
を繰り返す方式は採用しない。

Noriが目的・安全境界・正式承認を行い、その範囲内でCodex側が
**調査 → 評価 → 次対象選定 → 必要な追加調査 → 独立監査 → 是正 → 再監査**
を自走する方式へ切り替える。

対象は主に残存G1、G3、G4、G5。必要に応じてPhase 1棚卸し済み候補から関連性の強い対象を追加選定可能とする案。
