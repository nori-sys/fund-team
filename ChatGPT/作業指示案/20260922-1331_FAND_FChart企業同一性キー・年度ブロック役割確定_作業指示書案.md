# 20260922-1331_FAND_FChart企業同一性キー・年度ブロック役割確定_作業指示書案

> 状態：未承認案・実行禁止

## 01）目的

FChart企業業績データの正式仕様化を阻害している最大の未確定事項である、

1. FChart企業業績DATと上場企業を安定して結び付ける企業同一性キー
2. 企業業績DAT内の年度ブロック候補（443 / 498 / 553 / 608 / 663）の役割と年度対応

を解明し、企業コード・企業・決算期・年度ブロックを再現可能に対応付けられる状態を目指す。

本作業は、前段で有力候補となった相対offset 7 / 11 / 15 / 19の項目意味を新たに探索する作業ではなく、それらを正しく検証するための「企業識別」と「年度識別」の基盤を確立することを目的とする。

## 02）対象・範囲

### A. 企業同一性キーの解明

既存のFChart関連ファイル、既存成果物及び必要な設定・索引ファイルを用い、次の関係を調査する。

- 証券コード
- 銘柄名
- `kabu.lst`
- `Userkabu.ini`
- `kigyo.dat` / 関連企業業績DAT
- その他、企業データ位置又は企業識別に関与するファイル

既存の候補座標や行番号をそのまま正式キーと仮定せず、複数銘柄で再現し、企業同一性を一意に説明できる規則を探索する。

### B. 年度ブロック役割の確定

既存調査で候補となっている以下のブロックを主対象とする。

- 443
- 498
- 553
- 608
- 663

各ブロックについて、

- 先頭の `YYMM`
- 決算期
- 時系列上の並び
- 実績 / 予想
- 連結 / 単体
- 会計基準
- 更新時の世代移動
- 最新期 / 過年度の関係

を可能な範囲で検証し、各ブロックが何を表すかを説明する。

### C. 既存4項目候補との整合確認

企業同一性と年度ブロック役割が確定又は高確度化した標本についてのみ、次の既存仮説との整合を確認する。

- 相対offset 7：売上高候補
- 相対offset 11：営業利益候補
- 相対offset 15：経常利益候補
- 相対offset 19：純利益候補
- 値表現候補：signed little-endian 32-bit、百万円

本作業では4項目の正式仕様化そのものは主目的としないが、企業・年度対応が確立した結果として10銘柄以上・各3期以上の再現条件を満たせる場合は、次段階で正式仕様化できる根拠として整理する。

### D. 対象外

- 正式DBへの投入
- FChart原本の変更
- FChart企業業績DATの書換え
- API実装
- IRBankの主系統採用
- 新規の企業業績データ源の本格導入

- 1～2銘柄のみの一致で企業同一性規則を確定しない。
- `YYMM`一致だけで年度ブロック役割を確定しない。
- 不一致や例外を除外して都合のよい標本だけで規則化しない。
- 企業名文字列、証券コード、レコード内値等、独立した複数の証拠を可能な範囲で組み合わせる。
- 不明事項を推測で確定しない。

- FChart原本及び関連資産は読取りを原則とする。

## 06）合格条件・完了条件

### 6-1. 企業同一性キー

次を満たした場合に「確定可能」と判定する。

- 証券コード又は同等の一意な企業識別子とFChart企業業績DATの対象レコード又は位置を、再現可能な規則で結び付けられる。
- 複数銘柄で同一規則が再現する。
- 異なるファイル世代又は更新時点でも規則が説明できる、又は適用範囲が明確である。
- 既知の例外が整理されている。
- 候補座標や偶然の行一致だけに依存しない。
- 独立監査で再現できる。

### 6-2. 年度ブロック役割

次を満たした場合に「確定可能」と判定する。

- 443 / 498 / 553 / 608 / 663の各ブロックについて、決算期との対応又は世代順序を再現可能に説明できる。
- 複数銘柄・複数決算期で同じ規則が成立する。
- `YYMM`だけでなく、内容値・時系列・一次開示等の独立証拠と矛盾しない。
- 実績 / 予想、連結 / 単体等が区別できない場合は、その未確定範囲を明示する。
- 既知の例外と適用範囲が整理されている。
- 独立監査で再現できる。

### 6-3. 次工程移行判定

企業同一性と年度対応が確立し、10銘柄以上・各3期以上について4項目を正しく照合できる標本が構築できた場合、

「offset 7 / 11 / 15 / 19の正式仕様化再検証へ進行可能」

と判定する。

条件未達の場合は、不足要因と最小追加調査を具体化する。

### 6-4. 独立監査

現行監査運用に従い、要修正時は是正・再監査を反復し、「適合（承認可）」まで収束する。
