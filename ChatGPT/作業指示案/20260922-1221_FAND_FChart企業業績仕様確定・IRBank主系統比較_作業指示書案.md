# 20260922-1221_FAND_FChart企業業績仕様確定・IRBank主系統比較_作業指示書案

> 状態：未承認案・実行禁止

## 01）目的

前段のIRBank照合PoCで有力化したFChart企業業績データの `block offset 608` 仮説について、複数銘柄・複数年度・一次開示資料を用いて再現検証し、売上高・営業利益・経常利益・純利益の4項目をSOSIA FANDで正式仕様化できる水準に達したか判定する。

同時に、SOSIA FANDの企業業績データについてFChartとIRBankを比較し、今後の主系統・補助系統の役割分担を決定できる根拠を提示する。

本作業の狙いは、単なる追加探索ではなく、既存の有力仮説を意図的に反証可能な形で検証し、企業業績データ基盤の次段階へ進むための仕様判断材料を確定することである。

## 02）対象・範囲

### A. FChart企業業績仕様の再現検証

前段PoCで有力候補となった次の仮説を主対象とする。

- block offset 608 内 相対offset 7：売上高候補
- block offset 608 内 相対offset 11：営業利益候補
- block offset 608 内 相対offset 15：経常利益候補
- block offset 608 内 相対offset 19：純利益候補
- 値表現候補：百万円単位、signed little-endian 32-bit

既存成果物、FChart関連ファイル、IRBank取得済みデータ、必要な一次開示資料を照合し、企業同一性・決算期・連結/単体・会計基準・実績/予想等の対応を確認したうえで検証する。

前段PoC成果物：
- `IRBank_FChart企業業績照合結果.md`
- `IRBank_FChart項目対応比較表.csv`
- `未確定事項・追加調査候補.md`
- `IRBank_FChart企業業績照合_独立監査結果.md`

`D:\投資・トレード\株式\株式データ\IR BANK\fy-profit-and-loss.csv`

### B. 再現性検証の標本

可能な限り、企業コードと決算期を正式に対応付けられる銘柄を使用する。

最低限、仕様確定判定を行う場合は次を満たすこと。

- 10銘柄以上
- 各銘柄3決算期以上を原則とする
- 黒字・赤字又は利益符号の変化を含む
- 売上規模の異なる企業を含む
- 利益変動の大きい企業を含む
- 前段で一致した事例だけに標本を偏らせない

利用可能なデータが上記を満たさない場合は、無理に仕様確定せず、未達理由を報告する。

### C. 一次開示との照合

IRBankだけを正解値とせず、検証可能な範囲でEDINET、TDnet、企業の正式開示資料等の一次情報と照合する。

少なくとも、仕様確定の根拠となる代表標本については一次開示値との整合を確認する。

### D. FChart / IRBank の主系統比較

企業業績データ源として次を比較する。

- 正確性・一次開示との整合性
- 銘柄網羅性
- 年度・履歴の長さ
- 項目網羅性
- 更新速度・更新安定性
- 企業識別キーと決算期識別の安定性
- 継続取得・自動化の容易さ
- データ形式の再現性
- SOSIA FAND既存DB/FChart株価基盤との親和性
- 利用規約・ライセンス・法人利用・商用利用上の制約
- 第三者データ依存リスク
- 将来の保守性

結論は必ずしも一方への全面統一を前提とせず、必要なら
「企業業績はAを主系統、Bを検証・補完」
「株価はFChart、企業業績は別系統」
等の役割分担も候補とする。

## 06）合格条件・完了条件

### 6-1. offset 608仕様判定

次をすべて満たした場合に限り、4項目を「仕様として確定可能」と判定できる。

- 企業同一性が確認できる標本で検証している。
- 複数銘柄・複数年度で同じ相対offsetと値表現が再現する。
- 売上高・営業利益・経常利益・純利益の4項目が一貫した並びで説明できる。
- 赤字等のsigned値を含め、値表現が矛盾しない。
- 代表標本について一次開示値と整合する。
- 不一致事例がある場合、その原因を説明でき、仕様仮説と矛盾しないことを示せる。
- 既知の例外と適用範囲が明記されている。
- 独立監査で根拠の追跡性と再現性を確認できる。

上記を満たさない場合は、確定を強行せず「棄却」又は「継続未確定」とする。

### 6-2. データ源採用判断

FChartとIRBankについて、比較項目ごとの根拠を示し、SOSIA FANDの企業業績データについて主系統・補助系統の構成案を提示できること。

利用条件上の制約を含め、継続運用可能性を評価すること。

データ品質だけでなく、正確性、更新、履歴、識別、再現性、運用性、利用条件を含む総合判断とする。

Noriが最終採用判断を行えるだけの材料が揃っていることを完了条件とする。

### 6-3. 独立監査

現行の監査運用に従い、要修正の場合は是正・再監査を反復し、「適合（承認可）」まで収束させる。
