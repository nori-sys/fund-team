# FAND EDINET企業業績データ基盤 Phase1簡素化・実装前倒し 改定案

> 状態：未承認案
> 対象：`作業指示/20260923-1332_FAND_EDINET企業業績データ基盤_Phase1-5統合推進_作業指示書.md`
> 起案根拠：2026-09-24 Nori指示「データの検証精度を下げても仕事を前に進める。開発を進めるのに必要な改善を進める」
> 公開区分案：公開可（禁止情報を含めない）

## 01）目的

EDINETを金融庁が提供する公式一次情報として扱い、EDINET掲載値そのものの正当性をSOSIA FAND側で再審査することをやめる。

SOSIA FAND側の検証責任を、次の三点へ限定する。

1. 対象factの取り違えを防止できること。
2. EDINET上の出典へ追跡できること。
3. 同じ入力から同じ正規化結果を決定論的に再現できること。

Phase 1の過剰な証明作業を打ち切り、Phase 2・3を必要最小限で確定し、Phase 4の隔離実装PoCへ早期に到達する。

## 02）対象・範囲

### A. EDINET情報の信頼境界

EDINET公式公開情報に記録された提出書類、fact値、concept、context、period、unit、訂正関係その他の公式メタデータは、SOSIA FANDが再審査すべき外部データ品質問題とは扱わない。

SOSIA FANDは、EDINET公式情報から取得した値を独自に会計監査しない。

ただし、取得・抽出・正規化過程での取り違え、誤変換、重複、訂正前後の混同、期間の誤認、単位の誤認は検証対象とする。

### B. Phase 1の中核対象

Phase 1の合格判定対象は次だけとする。

- 2社
- 税引前利益
- 当期純利益
- 2024年3月期比較値
- 2025年3月期当期値
- 合計8セル

654候補全件の意味確定、全hold解除、9軸の網羅的解明はPhase 1完了条件から除外する。

中核8セル以外の候補は、Phase 1完了時点で未採用又はholdのまま残してよい。

### C. 最低限確認する属性

中核8セルについて、最低限次を確認する。

- 出典書類を一意に特定できる
- conceptを一意に特定できる
- contextから期間を判定できる
- 値とunitを取得できる
- 当期／比較期を区別できる
- 訂正書類が存在する場合、採用する最新版出典を識別できる
- 同じ保存済み入力と同じ処理版から同じ8セルを再生成できる

会計基準及び連結／単体は、EDINETの書類単位又は公式メタデータから確認でき、矛盾がなければfact単位の追加証明を要求しない。

dimension/memberが中核8セルの識別に不要で、候補競合を生じさせない場合は、詳細意味の完全解明をPhase 1合格条件としない。必要な場合だけ識別キーとして扱う。

### D. Phase 2・3の短縮

Phase 2では、Phase 4実装に必要な最小データモデルだけを版固定する。

最低項目：
- entity
- filing/document
- fact
- concept
- period
- value
- unit
- revision
- provenance
- validation_state
- hold_reason

会計基準、連結／単体、dimension/member等は保持可能な項目として設けるが、未確定値を `unknown/null` として保持できる設計を許容する。

Phase 3では、Phase 4実装に必要な最小運用設計だけを版固定する。

最低項目：
- 取得
- 冪等性
- 訂正追跡
- retry
- provenance
- validation/hold
- 本番資産境界
- 秘密情報非保存

Phase 4実装に不要な網羅的運用設計は後続課題へ送る。

## 03）保存先

現行1332正式作業指示書および承認済みWORKFLOWに従う。

本案だけでは正式作業指示書を変更しない。

## 04）制約・禁止事項

- EDINET公式値をSOSIA FAND側で独自に「正しい／誤り」と判定しない。
- 公式情報に存在しない属性を推測補完しない。
- 中核8セル以外のhold解消をPhase 1完了のために要求しない。
- 追加外部取得は、中核8セルの識別・最新版判定・再現性確認に直接必要な場合だけに限定する。
- 本番DB、正式コード、正式設定へ変更しない。
- Phase 4までは隔離PoCとして扱う。
- 安全性、秘密情報保護、本番資産非干渉は緩和しない。

## 06）合格条件・完了条件

### Phase 1

次をすべて満たせば合格とする。

1. 中核8セルを一意に抽出できる。
2. 各セルについて出典書類、concept、period、value、unitを追跡できる。
3. 当期／比較期を正しく区別できる。
4. 訂正関係がある場合は、採用する最新版出典を識別できる。
5. 同一入力・同一処理版で再実行し、8セルの採用集合と値が一致する。
6. 取り違え、期間誤認、単位誤認、訂正前後混同がない。
7. 中核外holdは非採用のまま隔離され、Phase 2入力へ混入しない。
8. 独立監査で上記が確認できる。

次はPhase 1不合格理由としない。

- 654候補全件の意味未確定
- 中核外holdの残存
- 9軸の未解明
- fact単位の会計基準の追加証明不足。ただし書類単位の公式情報との矛盾がないこと
- fact単位の連結／単体の追加証明不足。ただし書類単位の公式情報との矛盾がないこと
- 中核識別に不要なdimension/memberの意味未解明

### Phase 2

Phase 4で中核データを保存・検索・訂正追跡・provenance確認できる最小モデルが版固定されれば合格とする。

### Phase 3

Phase 4で必要な取得・再実行・訂正・冪等性・hold・障害処理・安全境界が実装可能な仕様として版固定されれば合格とする。

### Phase 4開始条件

Phase 1～3の各最低合格条件を満たし、独立監査が適合であれば、網羅的な未解明事項が残っていてもPhase 4へ進める。

## 07）公開区分

## 08）通常運用からの例外

1332正式作業指示書のPhase 1合格条件を、本案の正式承認後に上記最小条件へ置換する。

Phase 1～3で未解明事項が残っていても、Phase 4実装に必要な最低条件を満たし、安全上の停止条件に該当しなければ次Phaseへ進める。

ただし、安全性、権限、本番資産保護、秘密情報保護、独立監査、本番採用のNori最終判断は緩和しない。
