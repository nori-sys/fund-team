# ChatGPT 作業指示案

このフォルダは、ChatGPTが作成したCodex向け作業指示案を保存するための領域である。

## 位置付け

このフォルダ内の文書は、原則として次の状態である。

- 未承認
- 未発行
- Codexの正式な実行根拠ではない

Codexは、このフォルダに文書が存在することだけを理由として作業を開始してはならない。

## 正式化

Noriが内容を確認し正式承認した作業指示のみ、正式な `作業指示/` の運用に従って実行対象とする。

## 用途

この領域は主として、

ChatGPT → Nori確認 → 正式作業指示 → Codex

の受け渡しを効率化するために使用する。

正式規程、ROLE、WORKFLOWまたは正式成果物の保存場所として使用しない。
