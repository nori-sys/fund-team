# レコード構造調査結果

作業ID: 20260722-01

## 確定

- `kigyo.dat` はファイルサイズ 8,610,226 byte が `823 byte * 10,462 record` に完全一致する。
- `kigyo2.dat` はファイルサイズ 3,452,460 byte が `330 byte * 10,462 record` に完全一致する。
- `kigyo3.dat` はファイルサイズ 3,452,460 byte が `330 byte * 10,462 record` に完全一致する。
- 上記3ファイルはヘッダーなし固定長レコードとして扱える可能性が高く、末尾余剰はない。
- 文字列は主にCP932で抽出できる。`kigyo.dat` には企業概要らしい日本語文字列が含まれる。

## 有力

- `kigyo.dat` レコード先頭4 byteはリトルエンディアン整数で、kabu.lst先頭コードと一致する例がある。例: 先頭レコード `E9 03 00 00` = 1001、2レコード目 `F2 03 00 00` = 1010。
- `kigyo.dat` にはレコード内オフセット 113,168,223,278,333,443,498,553,608,663 付近に `YYMM` 形式らしい決算期候補が反復する。
- `kigyo2.dat` / `kigyo3.dat` は 55 byte単位の小ブロックが6個並ぶ構造が有力で、各ブロック先頭付近に `YYMM` 日付候補がある。
- `kigyo.dat` の後半、主にオフセット 772 付近に企業概要らしいCP932文字列領域がある。

## 仮説

- `kigyo.dat` は銘柄単位の基本情報および年度/期別の業績サマリを保持している可能性が高い。
- `kigyo2.dat` / `kigyo3.dat` は同一銘柄順で、年度範囲または用途が異なる業績サマリを保持している可能性がある。
- `Zaimu.dat` はゼロ領域が大きく、単純な `10,462 record` 固定長には現時点で一致しない。詳細財務または可変/複合形式の可能性がある。

## 不明

- `Zaimu.dat` の正確なレコード境界、ヘッダー長、レコード数は未確定。
- 数値項目名、倍率、単位、小数点位置はFChart画面表示値との照合なしでは確定できない。
- 欠損値・未設定値の表現は未確定。ゼロ埋めを欠損と断定しない。
