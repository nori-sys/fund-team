# 日付・数値形式調査結果

作業ID: 20260722-01

## 日付形式

### 確定

- CP932/ASCIIとして `9303`、`2203`、`2603`、`070201`、`260206` などの4桁・6桁数字列を抽出できた。

### 有力

- 4桁値は `YYMM`、6桁値は `YYMMDD` の日付形式候補である。
- `kigyo.dat` ではレコード内に複数年度の `YYMM` が一定間隔で並ぶ。
- `kigyo2.dat` / `kigyo3.dat` では55 byte単位のブロックに `YYMM` と `YYMMDD` 候補が含まれる。

### 不明

- それぞれが決算期、決算発表日、予想発表日、更新日のどれに該当するかは未確定。

## 数値形式

### 有力

- 多数の4 byte値はリトルエンディアン整数、または固定小数点/浮動小数点として解釈できる候補がある。
- `kigyo.dat` / `kigyo2.dat` / `kigyo3.dat` には年度ブロック内に小さな整数、負数、IEEE754らしいバイト列が混在する。

### 不明

- 売上高、利益、EPS等の項目名、倍率、単位は未確定。
- 欠損値、0、空欄、特殊値の区別は未確定。

## 追加検証条件

- FChart画面上の同一銘柄・同一年度の表示値が必要。
- 最低3銘柄以上、複数年度で一致を確認する必要がある。
