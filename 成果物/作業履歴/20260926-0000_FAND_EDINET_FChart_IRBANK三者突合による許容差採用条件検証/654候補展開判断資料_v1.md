# 654候補への展開判断資料 v1

判断：現時点で全体654候補へ0.5％許容差規則を展開しない。今回の検証は固定8セルのみで、実データの数値比較は0組である。0.5％が投資分析に必要十分な閾値か、企業業績値の採用条件として安全かは確認できていない。

展開を検討する前提は、少なくとも次のとおり。

1. EDINET公式表示系列、期間役割、訂正後出典とfactの一意対応が確認でき、0310のaccepted条件を満たすこと。
2. FChartの企業同一性キー、年度ブロック、対象指標（税引前利益を含む）の意味対応が独立した証拠で確定すること。既存の4指標仮説を正式仕様と扱わないこと。
3. IRBANK等の比較源について、企業・年度・連結/単体・訂正関係・単位・表示精度と利用権限が確認できること。
4. 0、0近傍、符号反転、単位換算、丸め区間の境界、比較源間衝突及び欠損を決定論的に処理し、固定8セル外への適用が別途承認されること。

これらは次工程の条件であり、追加取得、実装、本番接続、654件の個別再判定又は元状態変更を許可するものではない。実データが比較不能だった理由を解消するには、必要な証拠・利用権限・最小対象を別案として示し、Noriの判断を受ける必要がある。
